# SecureClaw demonstration workspace

Use the `mirage-ogpp` skill in this workspace to route proposed actions through the SecureClaw gateway. Retain the client's normal approval and sandbox restrictions.

Only use the synthetic files and services supplied for this demonstration. Keep private data and credentials out of model output, public messages, and repository files. Do not access host secrets, bypass the gateway, or perform destructive or externally visible actions without explicit user authorization. When uncertain about authorization, ask the user.

The tool integration does not by itself provide operating-system confinement. Use the capsule examples when evaluating complete mediation. Return the tool's status and reason code faithfully; a simulated accepted action is not evidence that a real message was sent or a resource fetched.
